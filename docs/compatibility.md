# 互換性

## 検証した環境

| 項目 | バージョン |
| --- | --- |
| Geyser-Spigot | 2.12.0-SNAPSHOT、build 3080 |
| Geyserコミット | `e215fa5cf1ffc3874c4d46c579d25800b20f17e4` |
| Paper | 26.3-159-main@a4b87cf |
| Bedrock | 1.26.51、protocol 2193 |
| 実行用Java | 26 |
| ビルド | JDK 25以上、Python 3 |
| 統合テスト | Node.js 24以上、bedrock-protocol 3.60.1 |

検証したGeyser JARのSHA-256は `424cba7e10e81c0655839fd3fdc2aeaac3962ffd7d6b0222a8fe2552ac5c859c` です。拡張APIの宣言は2.12.0ですが、Geyserの内部クラス・定義にも依存します。API番号が同じことだけで互換性を保証しません。

Standalone・Velocity、別のGeyserビルド、別のBedrockプロトコルの描画・操作は未確認です。HUDの固定AUXは検証したGeyserの26.50 item statesから生成します。

## 操作と表示

通常のプレイヤーインベントリのオフハンド操作を対象としています。クリエイティブの一覧、別のコンテナ画面、ほかのカスタムアイテム拡張との同時使用は個別の確認が必要です。

オフハンドのブロックが小さく見える現象は、参照したDoubleHandsの説明でもBedrock側の表示制約として扱われています。現在の実装では、ブロックの拡大やプレイヤーの腕補正を追加しません。インベントリ表示中の道具には専用の保持モデルを使用し、ゲーム画面の保持アイテムには元のバニラ定義を使用します。

食品・ポーションの消費はJava側で処理します。左手の独自の食事・飲用アニメーションはありません。食事モーションやすべての保持位置がバニラと同一であることを保証するものではありません。

HUDのAUXは完全なアイテムスタックではありません。ポーションの色、染色、盾・旗の模様、エンチャント表現は未確認です。65種類の生成設定も全件の実機描画を確認したものではありません。[確認状況](validation.md)を参照してください。

## ほかの画面表示・使用判定

通常のタイトルと副題をオフハンドHUDへ使用するため、サーバーから送られた通常タイトル・副題は表示されません。アクションバーは元のGeyserの処理を使います。

Bedrockの使用パケットには手の指定がないため、Javaのすべての使用判定を完全に再現しているわけではありません。右手で使用できるアイテムを優先し、空の右手や剣などの場合は左手の使用へ送ります。満腹時の食品など、状態によって使用できなくなる右手のアイテムは追加検証が必要です。
