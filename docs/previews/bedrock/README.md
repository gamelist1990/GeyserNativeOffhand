# Bedrock のモデル確認

現在の候補は **RP 0.1.14 / extension 0.1.3-attachable.12** です。

[0.1.13 の実際の食品モデルの比較と数値](0.1.13/README.md)。0.1.14 の食品・道具のモデルとアニメーションは同一です。0.1.14 ではブロックの元のアイテム種類を保持し、独自の描画コンポーネントと腕の補正を適用しません。実機の確認待ちです。

[0.1.12 の過去のプレビュー](0.1.12/README.md) は、実機で斧・ブロック・パンの表示不良が残った版です。道具には代用形状を使っており、Blockbench の条件式インポートにも座標の反転差がありました。この版の画像を描画修正の完了証拠として扱わないでください。

どのプレビューも Bedrock 本体の組み込みアイテム描画を実行しません。サーバーのパケット検証と実機の描画検証は別々に記録します。
