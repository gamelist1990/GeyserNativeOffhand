# インベントリ用定義とバニラ装備パケット

0.2.5 の実機確認でも、インベントリ表示中のオフハンドの斧はバニラと異なる向きでした。道具のフラグや文字列プリセットだけでは改善しませんでした。

0.2.6 は通常のインベントリからオフハンドへ移すためのカスタム定義を維持し、インベントリ表示・更新の処理が終わった後に、両手へ元のバニラ定義を使った `MobEquipmentPacket` を送ります。斧の型・描画はバニラ側で扱う候補です。右手用の角度を左手へ当てる補正は作成しません。

## 処理

1. Geyser のインベントリ処理を、移動用の定義を選ぶスコープ内で実行します。
2. スコープを外して Java のメインハンドとオフハンドを翻訳します。
3. 両手の装備パケットを送り、UI 用スタックのネットワーク ID は付けません。
4. 閉じる際は、これまでと同じくバニラのインベントリ定義へ戻し、表示のキャッシュを更新します。

元の Geyser の LivingEntity も装備パケットへ翻訳したアイテムを送ります。本候補ではローカルプレイヤーの表示中のインベントリにもこれを適用します。Bedrock クライアントが自己の装備パケットを UI のアイテムと別に描画できるかは、実機で確認が必要です。パケット検査だけでは有効と判定できません。

元の DoubleHands HUD、Java の種類・個数・名前・耐久値・エンチャント、通常のインベントリ操作、オフハンド使用は維持します。保持用の attachable やプレイヤーのボーン補正は追加しません。0.2.5 の効果がなかった描画プリセットは削除します。

## 確認項目

自動試験では 23 種類のインベントリ往復中に、右手と左手の装備パケットが元のバニラ ID・ブロック状態・データ値・個数であることも確認します。自動クライアントは Bedrock の描画処理を実行しません。

実機では右手に剣・左手に斧を持ち、インベントリを開閉して向き・大きさを確認します。開いている間の斧の出し入れ、剣・食品との交換、ブロックの移動も確認し、表示の変更でオフハンド移動ができなくなっていないかを判定します。

Paper/Geyser で 70 項目が通過しました。0.2.6 の実機では左手の斧の向きが変わらず、表示の修正に失敗しました。

0.2.7 では効果がなかった表示中の装備パケット補正と、その補正専用の自動検査を削除しました。閉じる際のバニラへの復元と表示更新は維持します。次の候補は [UI 用道具の attachable](ui-tool-attachables.md) です。
