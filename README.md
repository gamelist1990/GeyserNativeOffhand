# GeyserNativeOffhand

Geyser経由でJavaサーバーに参加するBedrockプレイヤーが、通常のインベントリからアイテムをオフハンドへ出し入れできるGeyser-Spigot拡張です。ホットバーの左には、オフハンドのアイコンと個数を表示します。

現在のソース版は **0.2.33** です。

## 機能

- 持ち物欄・ホットバーとオフハンドの間で、アイテムを移動・分割・結合・交換できます。
- 押しっぱなしの設置は4クライアントtick（通常約200ms）間隔です。照準の場所や面が変わっても連射間隔をリセットしません。
- ブロック、道具、食品などをオフハンドに持ち、設置・使用を同じPaperサーバーの実処理で判定します。右手のブロック操作、右手のアイテム使用、左手の順に処理し、成功・FAILに応じて停止します。
- タッチ操作／Pocket UIでは、持ち物画面を開いている間に移動用定義を使い、スロット選択→オフハンドへの直接移動に対応します。閉じるとバニラ定義へ戻ります。実機のタップ操作は確認待ちです。
- PCでは通常の持ち物欄と左右の手はバニラ定義を使います。オフハンドへ移動するための定義は、持ち物欄で掴んだアイテムと、結合先になる同じ種類のスタックにだけ一時的に使います。置き終わったら元へ戻ります。
- オフハンドのHUDはクライアントの既存アイコンを使います。同梱パックは約9.7KBです。

## 対応環境

| 項目 | 検証済み環境 |
| --- | --- |
| Geyser | Geyser-Spigot 2.12.0-SNAPSHOT、build 3080 |
| Javaサーバー | 同じサーバーのPaper 26.3-159、Java 26 |
| Bedrockクライアント | 1.26.51 |

Geyser-Spigot向けです。ほかのGeyserビルドやStandalone・Velocityの対応状況は[互換性](docs/compatibility.md)を参照してください。

## 導入

1. [ビルド手順](docs/building.md)に従って拡張JARを用意し、サーバーを停止します。
2. JARを `plugins/Geyser-Spigot/extensions/` に配置します。更新時は古い本拡張のJARを取り除きます。
3. Geyserの設定で、次の既存の項目を `true` にします。

```yaml
gameplay:
  enable-custom-content: true
  force-resource-packs: true
  enable-integrated-pack: true
```

4. サーバーを完全に再起動します。リソースパックは拡張から自動登録されます。
5. Bedrockから再接続し、配信されたリソースパックを受け取ります。

インベントリを開き、アイテムを一度掴んでから通常のオフハンド枠へ置いてください。専用コマンドやフォームは必要ありません。

## 利用上の制約

- オフハンドのブロックは、Bedrock側の表示制約で小さく見える場合があります。
- 食品の消費はJavaサーバー側で処理します。専用の左手食事アニメーションはありません。石・斧・パンの移動と画面切り替え時の一瞬の消失解消は実機で確認しています。
- 通常のタイトルと副題はHUDに使用するため表示されません。アクションバーは利用できます。
- アイコンの色・模様・エンチャント表現や、クリエイティブ・ほかのカスタムパックとの組み合わせは、[確認状況](docs/validation.md)を参照してください。

0.2.23ではパン・石・りんご・ランタンのHUD表示と切り替えを実機で確認しています。0.2.30のスタック結合は実機確認済みです。0.2.31では設置・使用をPaperの実判定へ切り替えました。[設置処理と対応範囲](docs/vanilla-placement.md)を参照してください。詳しい実装・検証・過去の記録は[docs](docs/README.md)にまとめています。
